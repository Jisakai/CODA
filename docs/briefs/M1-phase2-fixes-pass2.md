## Confirmed blockers remaining after pass1

A. Persistent ADSR stages, not amplitude guessing. Lines190–192 decide attack whenever amp<1, so after one decay sample it attacks again forever. Explicit attack/decay/sustain/release/idle state per voice with legitimate transitions. Pluck held through decay reaches zero/no sustain; pad/lead reach configured sustain. Note-off during attack/decay releases from current level continuously. Shape changes smoothly modify timing without restarting stages; preset-switch policy must be explicit for already-active voices. Tests must assert stage/amp or isolated envelope output at known times, including zero-sustain idle and release durations. Do not rely on wet RMS to infer envelope.

B. Actual sample-rate-derived stable EQ. Chords HP now uses state += coefficient*(input-previousInput); this telescopes to coefficient*input and fails DC rejection. Use a known correct HP recurrence or input-minus-real-LP with an independently tested DC response. Chords HP~120Hz and gentle highcut~9kHz. Master must process SUM dry+wet, gentle high attenuation~8–10kHz and a broad LOCALIZED ~2–4kHz dip. Current input+HP term boosts highs, subtracting LP cuts lows; these aren't the intended responses. Proper biquad high shelf/peaking EQ or equivalent stable known design; prepare coefficients off-render. Tests measure DC step decay and sine gain at low/mid/high frequencies across44.1/48/96kHz, including expected attenuation direction and return outside dip. Factor production filter units for testing instead of writing a test-only replica; verify actual state reset/production wiring.

C. Mute latch/state machine. rv=muted?0 already kills reverb immediately, before output fade. Unmuting before zero prevents invalidation forever and brings stale wet back; same-block mute/unmute is another case. On mute request latch fade-to-zero, keep existing dry/wet path continuous during fade, invalidate generation/filter state in bounded work ONLY at zero, then permit a pending unmute fade. No bulk clears/allocations in render. Tests must exercise audible wet tail + quick unmute, same-block toggles, output continuity/difference against unmuted reference, and stale-tail silence after unmute (render long enough to reach old delayed taps). Document actual8ms or12ms single tunable duration, not conflicting docs.

D. Correct glide predecessor. Current search any releasing rank can use an older chord when counts shrink/expand. Only use the immediately preceding harmonic region's sorted-rank frequencies, captured coherently before new onsets mutate voices. Treat ranks missing in preceding region explicitly; document matching policy consistent with sorted rank matching. Test2notes->1note->2notes with old tails still active and stale offs: rank1 cannot glide from old-old region. No allocation on render; bounded fixed snapshot. Keep per-preset defaults and working glide amounts all presets.

E. Accepted event timing guarantee. max32 due events/sample silently shifts33rd accepted event a sample late. Either enforce/report an admission limit at publication before accepting (and document producer contract), or process a bounded immutable snapshot that preserves every admitted offset. No unbounded drains under refill, no silently late accepted groups. Validate event ordering/invalid ranks appropriately. Test limit-1/limit/limit+1 including off-before-on and full queue recovery; every accepted event executes at its advertised sample, overflow visibly rejected. Tests needing queue fullness must not depend on invalid simultaneous burst groups. Keep capacity bounded and lock-free.

F. Real diffuse long damped reverb. Current line0 has no feedback, direct injection bypasses predelay, other lines get strongly attenuated average; it doesn't provide documented long decay. Use a small correct preallocated parallel comb + diffuser or stable FDN, driven by predelay~20ms, with sample-rate-derived damping/timing and coherent decay tuning. Known feedback paths, no immediate dry bypass in wet output, all lines with real returns, stable max controls/denormals. Tests on production unit: no wet response before predelay, nontrivial diffusion/tail, measurable decay over intended duration, finite/bounded output across sample rates, no DC runaway. Report exact constants; short feedback echo is not a hall. Mono acceptable with honest docs.

G. Stop lifecycle. coda_dsp_stop mutates voices, pending/target/generation and pops queue on control thread; races process if overlapped. Either require all prepare/reset/stop/destroy under full render AND producer quiescence in public header/docs, with runtime caller contract, or implement stop as an ordered render-consumed request. No second queue consumer concurrently. No false statement that stop leaves tails to decay if it invalidates immediately. Add appropriate stop/resume/queued-events tests.
