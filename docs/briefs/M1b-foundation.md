## Model and editing
- Separate immutable, Equatable/Sendable pattern arrangement, pattern region, stroke and settings values. Validate arrangement.barCount in 1...MusicDefaults.canvasBars. Explicit nonempty nonoverlapping half-open zero-based bar ranges within that bar count, with checked arithmetic, independent of chord-region identity. At compilation require arrangement.barCount * stepsPerBar == progression.totalSteps; reject mismatch rather than implicitly resizing/rebasing. Exactly eight optional slots per pattern; repeat those slots each bar. IDs nonempty and unique within their owning namespace; validate duplicate stroke IDs across an arrangement as well as duplicate region IDs.
- ArrowLevel stores one validated integer 1...10. normalizedLength and baseVelocity MUST derive from the same level/10 value. Readout is a percentage of that SAME base, e.g. v10...v100; do not quantize through MIDI 127 or apply a 90%-height multiplier. Zero is absence. Explicit pure length conversion: finite normalized length <=0 means absence; positive length rounds to nearest tenth, halfway away from zero, then clamps to 1...10; positive values over 1 clamp to level10. Clamp above 1 BEFORE multiplication or integer conversion so Double.greatestFiniteMagnitude cannot trap; a tiny positive finite value still yields level1. Nonfinite input errors. Continuous chuck size is separately finite/validated in (0,1], not rounded to tenths.
- Model directions down/up; base velocity is independent of later Loose variation. Data-driven Pop Rock preset slots D,empty,D,U,empty,U,D,U, with shared default level8, not special compiler branches. Preset data must be reusable without fixed identity collisions: instantiation requires explicit fresh IDs for each occupied stroke; duplication likewise requires fresh region/stroke IDs. A Swift value array is sufficient data; no resource/dependency needed.
- PatternEditor mirrors ProgressionEditor: validate a candidate FINAL arrangement before one atomic commit; intermediate overlaps allowed within a transaction. Failed/no-op edits preserve state AND redo. Preview returns a candidate without history. Undo/redo restores complete settings/slots/ranges/IDs. Edits retain IDs; duplication requires explicit fresh IDs, including strokes.
- Single PatternDefaults.defaultScope = wholeLoop resolves to an explicit range in absolute arrangement-bar coordinates from LoopSpan.start and length when applying. LoopSpan.start/length are GRID STEPS: divide by MusicDefaults.stepsPerBar, then validate against arrangement.barCount. For start32/bars2 the resolved range is bars[2,4), not[0,2). Do not bury a second independent scope default elsewhere.

## Chosen provisional feel defaults — not owner decisions
All values below are tunable implementation defaults under SPEC §8's approximate ranges and must be documented for Hermes to add to DECISIONS_LOG after review. They are not claims of listening acceptance.
- Per-pattern swing defaults 0, accepted normalized amount 0...1. Delay odd eighth slots by amount * one sixteenth-note duration (half an eighth). Even slots unaffected.
- Tight initially. Spread defaults 20ms, range 0...60ms, interpreted as TOTAL first-to-last onset duration, not per-string delay; singleton has zero spread.
- Loose: versioned deterministic integer PRNG/hash with explicit seed, cycle index and stable region/bar/slot/note identities; never Swift Hasher or global randomness. One shared timing jitter per stroke within ±3ms; per-note velocity within ±6/127, detune ±3 cents, normalized filter delta ±0.02. Clamp effective audible velocity to [0.01,1], leaving baseVelocity unchanged. Tight has exactly zero variation.
- Chuck baseVelocity equals normalizedSize without tenth quantization; Tight effectiveVelocity equals baseVelocity, including tiny positive sizes. Loose follows the same per-stroke/per-note modulation rules as arrows. Chuck uses distinct attack mode on note instances, low-to-high short rake over total 12ms. Each retained chuck note ends at min(its adjusted onset + 40ms, ownership end, same-pitch replacement, subsequent chuck damping). Damp previously held instances ONCE at the first retained chuck onset using ordinary exact-instance offs. Cancel pending onsets belonging to earlier strokes at or after that damping point; a chuck with no retained onsets emits no damping. These are provisional compiler timing defaults; synth envelope/noise/filter behavior belongs to slice2, not a new engine here.

## Independent event compiler — never the old lossy bridge
Keep NoteEventCompiler.compile unchanged. New PatternEventCompiler first validates the checked arrangement/progression dimension equality required above; mismatch is a pattern-compiler precondition error, even if another input is also invalid. For matching dimensions, return an explicit legacy(CompiledLoop) branch when no pattern region intersects the playback span, delegating directly so origin/count/events/order/errors match exactly. Test both the precondition precedence and exact legacy equivalence for matching dimensions. Applied all-empty pattern is NOT absent pattern. Pattern output owns immutable off-thread arrays/identity metadata only; no session publication or render-owned Swift storage.

Define separate bounded numeric harmonic-region, stroke-occurrence and note-instance tokens; never overload harmonic identity with every retrigger. Preserve sorted ascending harmonic voice rank independently of down/up onset order. Carry sampleOffset, kind/off-before-on precedence, pitch, rank, onset ordinal, tokens, base/effective velocity, detune/filter and attack mode. Tokens are LOCAL to one compiled-cycle value; metadata includes cycle index/origin but conveys NO runtime generation uniqueness. Slice2 MUST qualify every ON/OFF with nonwrapping prepare-epoch and plan-generation identity, cycle and local instance token; restore/audition require fresh runtime ownership. No global allocator or native identity implementation belongs here. Offs identify the exact local instance. No wrapping exhausted tokens.

Use existing loop validation, checked arithmetic and 2^53 grid precision guards. For cycle c, loop length L, local fractional grid coordinate u and seconds adjustment d:
    offset = round((c*L + u)*samplesPerStep + d*sampleRate) - round(c*L*samplesPerStep)
Round absolute time ONCE, nearest-away-from-zero. Do not add jitter to already-rounded offsets or replay cycle-zero offsets forever. Adjacent cycle origins/counts must share the exact boundary. Reject invalid/nonfinite/collapsed timing.

Choose chord by NOMINAL eighth anchor, then swing/shared jitter/ordered spread. Clamp early jitter to the owning chord/pattern/loop interval; omit delayed ons at or past its end, never leak into the next chord/rest/range/cycle. Down is low-to-high; up high-to-low; ascending rank unchanged, including zero spread or sample ties.

Empty slots produce neither ons nor artificial offs. Each ordinary note sustains until chord end/rest, loop end, pattern-range boundary, chuck damping, or replacement onset of that same pitch, whichever comes first; chuck notes additionally honor their own adjusted-onset-relative gate above. Retrigger releases the exact previous instance immediately before the new on; no old scheduled off may release a replacement. Precompute onsets chronologically before deriving per-instance offs so opposite directions/large spread cannot invalidate ownership. After rounding onsets and applying chuck cancellation, coalesce attacks sharing ownership interval, pitch and sample BEFORE deriving offs: keep the latest nominal stroke occurrence, then onset ordinal/token as deterministic final tie-breakers. Discard superseded instances and their offs before lifetime/capacity validation; do not reject ordinary supported settings merely because they collide. Reject a remaining audible instance with collapsed nonpositive lifetime rather than silently publishing invalid events.

Mixed coverage: uncovered chord spans use simultaneous block attacks at chord start or return-to-uncovered boundary with legacy base velocity0.8/no modulation; clip at entering a pattern. Entering a pattern clips uncovered notes and adds NO implicit full-chord attack; only occupied nominal slots attack. At a chord change inside pattern coverage, old notes release and next chord waits for its next occupied slot. Pattern phase is absolute bar-local eighth index, not restarted by chord changes. Explicit loop start clips ownership; terminal offs occur at sampleCount.

Sort by sampleOffset, OFF before attack, deterministic occurrence/onset ordinal then stable token. Bound notes/chord <=12, total events <=3072, simultaneous events <=32, held notes <=12. Reject one-over/capacity failure before returning any result; never truncate. These are compilation limits, not proof of native queue/plan safety. Slice2 must separately extend native admission, epoch ownership, backpressure, seek/restore/audition and cycle-varying delivery. Do not publish through MusicSession's stepOffset-only CodaGridEvent conversion.
